    Paleoklimaat¶

    De CO₂-concentratie van de atmosfeer, 7530 jaar geleden, gemeten in een luchtbel in een ijskern.
    Domein paleoklimatologie
    Model plat, met een monsterketen en een afgeleide waarneming; twee alternatieven
    Bron illustratief
    Bestanden README (met de diagrammen) · alternatief 1 · alternatief 2

    De vraag¶

    Een luchtbel in een ijskern wordt verondersteld een monster te zijn van de atmosfeer op een moment in het verleden. Twee waarnemingen op de luchtbel leveren de CO₂-concentratie en de C14-leeftijd; een reconstructiemodel combineert ze tot de concentratie in de atmosfeer op die leeftijd.

    De keuzes¶

    • Een monsterketen: luchtbel isSampleOf ijskern isSampleOf aardkorst, en de luchtbel ook isSampleOf de atmosfeer. Elk monster is het resultaat van een bemonstering (de boring, de extractie) (R8, Monster en uiteindelijk studieobject).
    • Niet-kalendertijd: de fenomeentijd is 7530 jaar Before Present, met een benoemd tijdreferentiesysteem ex:BP (R9).
    • Software als sensor: het reconstructiemodel maakt de afgeleide waarneming.
    • De afgeleide waarneming gebruikt de resultaten van de twee bronwaarnemingen (sosa:hasInputValue) en verwijst naar de bronwaarnemingen met sosa:relatedObservation (R7).

    Twee alternatieven¶

    Alternatief 1 Alternatief 2
    inputwaarden de twee resultaten idem
    procedure beschrijft haar inputs in tekst heeft inputvariabelen (sosa:hasInput)
    koppeling waarde → variabele — p-plan:correspondsToVariable
    wat het oplevert eenvoud de gebruikte procedure is afleidbaar (P-PLAN en SOSA)

    De fout die rechtgezet werd¶

    De vorige versie van alternatief 1 gaf de bronwaarnemingen als inputwaarde. Een waarneming is een activiteit; met sosa:hasInputValue ⊂ prov:used wordt ze ook een entiteit, en PROV-O verklaart die twee disjunct. Rechtgezet op 2026-10-01, en mee de aanleiding voor de opname van het axioma in de W3C-module (SOSA en PROV-O).

    # fout                                          # juist
ex:Paleo sosa:hasInputValue ex:C14Observatie .  ex:Paleo sosa:hasInputValue ex:ResultaatC14Observatie ;
                                                         sosa:relatedObservation ex:C14Observatie .

## Voorbeeld 1: paleo atmosfeer
## De concentratie van CO₂ kan worden gemeten in luchtbellen in ijskernen, waarvan wordt aangenomen dat ze een steekproef vormen van de atmosfeer op een bepaald moment in het verleden.
## In dit geval zijn de concentratie en de leeftijd het resultaat van twee oorspronkelijke waarnemingen.
## Deze leveren de invoerwaarden voor de uiteindelijke waarneming.
## In dit voorbeeld krijgt de uiteindelijke observatie de resultaten van de 2 oorspronkelijke observaties als
## inputwaarden (sosa:hasInputValue), en verwijst ze naar de oorspronkelijke observaties zelf met
## sosa:relatedObservation. Een inputwaarde is een waarde (een prov:Entity, hasInputValue ⊂ prov:used), geen
## observatie: een observatie is een activiteit (sosa:Execution ⊂ prov:Activity). Zonder p-plan-variabelen;
## zie paleo_atmosfeer_alt.ttl voor de koppeling van de resultaten aan de inputvariabelen van de procedure.


ex:AardAtmosfeer a sosa:FeatureOfInterest ;
   sosa:isFeatureOfInterestOf ex:PaleoCO2Observatie ;
.

ex:AardKorst a sosa:FeatureOfInterest ;
   sosa:isFeatureOfInterestOf ex:BoringIjsKern ;
.

ex:IjsKern a sosa:Sample, sosa:FeatureOfInterest ;
   sosa:isSampleOf ex:AardKorst ;
   sosa:isResultOf ex:BoringIjsKern ;
   sosa:isFeatureOfInterestOf ex:ExtractieIjsBel ;
.

ex:IjsBel a sosa:Sample, sosa:FeatureOfInterest ;
   sosa:isSampleOf ex:IjsKern, ex:AardAtmosfeer ;
   sosa:isResultOf ex:ExtractieIjsBel ;
   sosa:isFeatureOfInterestOf ex:C14Observatie , ex:CO2Observatie ;
.

## Bemonsteringen: een monster is het resultaat van een sosa:Sampling (R8). Zo is ook elk studieobject
## in de bemonsteringsketen het FOI van een uitvoering.
ex:BoringIjsKern a sosa:Sampling , sosa:Execution ;
   rdfs:label "Boring van de ijskern"@nl ;
   sosa:hasFeatureOfInterest ex:AardKorst ;
   sosa:hasResult ex:IjsKern ;
.

ex:ExtractieIjsBel a sosa:Sampling , sosa:Execution ;
   rdfs:label "Extractie van een luchtbel uit de ijskern"@nl ;
   sosa:hasFeatureOfInterest ex:IjsKern ;
   sosa:hasResult ex:IjsBel ;
.

ex:C14Observatie a sosa:Observation , sosa:Execution ;
  sosa:observedProperty ex:C14Leeftijd ;
  sosa:hasFeatureOfInterest ex:IjsBel ;
  sosa:hasUltimateFeatureOfInterest ex:AardAtmosfeer ;
  sosa:hasResult ex:ResultaatC14Observatie ;
  sosa:usedProcedure ex:ProcedureC14Datering ;
  sosa:madeBySensor ex:AMS ;
  sosa:resultTime "2026-02-01T14:15:00+00:00"^^xsd:dateTime ;
.

ex:ResultaatC14Observatie a qudt:QuantityValue ;
  sosa:isResultOf ex:C14Observatie ;
  qudt:hasUnit unit:YR ;
  qudt:numericValue 7530.0 ;
.

ex:CO2Observatie a sosa:Observation , sosa:Execution ;
  sosa:observedProperty ex:CO2Concentratie ;
  sosa:hasFeatureOfInterest ex:IjsBel ;
  sosa:hasUltimateFeatureOfInterest ex:AardAtmosfeer ;
  sosa:hasResult ex:ResultaatCO2Observatie ;
  sosa:usedProcedure ex:ProcedureCO2Meting ;
  sosa:madeBySensor ex:Laserspectrometer ;
  sosa:resultTime "2026-02-01T14:16:00+00:00"^^xsd:dateTime ;
.

ex:ResultaatCO2Observatie a qudt:QuantityValue ;
  sosa:isResultOf ex:CO2Observatie ;
  qudt:hasUnit unit:PPM ;
  qudt:numericValue 240.0 ;
.

ex:PaleoCO2Observatie a sosa:Observation , sosa:Execution ;
  sosa:observedProperty ex:CO2Concentratie ;
  sosa:hasFeatureOfInterest ex:AardAtmosfeer ;
  sosa:hasResult [
      a qudt:QuantityValue ;
      qudt:hasUnit unit:PPM ; ## Parts per million (aantal deeltjes per miljoen deeltjes lucht
      qudt:numericValue 240.0 ;
  ] ;
  sosa:phenomenonTime [
    time:inTimePosition [
    time:hasTRS ex:BP ;
    time:numericPosition 7530 ;
    ] ;
  ] ;
  sosa:resultTime "2026-02-01T14:16:00+00:00"^^xsd:dateTime ;
  sosa:hasInputValue ex:ResultaatC14Observatie , ex:ResultaatCO2Observatie ;  ## de waarden
  sosa:relatedObservation ex:C14Observatie , ex:CO2Observatie ;            ## de observaties die ze opleverden
  sosa:usedProcedure ex:ProcedurePaleoCO2Contentratie ;
  sosa:madeBySensor ex:PaleoReconstructie ;
.

ex:ProcedurePaleoCO2Contentratie a sosa:ObservingProcedure , sosa:Procedure ;
   sosa:hasInput [
       dcterms:description "Resultaat van een observatie met als observedProperty de 'C14Leeftijd'" ;
   ] ;
   sosa:hasInput [
       dcterms:description "Resultaat van een observatie met als observedProperty de 'CO2Concentratie'" ;
   ] ;
   dcterms:description "Het resultaat van de CO2Concentratie-observatie is de concentratie CO2 in de atmosfeer in het verleden (phenomenonTime) op tijdstip gegeven door C14Leeftijd-observatie"@nl ;
.

ex:AMS a sosa:Sensor , sosa:System ;
   rdfs:label "Versnellermassaspectrometer (AMS)"@nl ;
   sosa:implements ex:ProcedureC14Datering ;
   sosa:observes ex:C14Leeftijd ;
.

ex:Laserspectrometer a sosa:Sensor , sosa:System ;
   rdfs:label "Laserabsorptiespectrometer"@nl ;
   sosa:implements ex:ProcedureCO2Meting ;

## De afgeleide observatie wordt gemaakt door software die de twee resultaten combineert.

## Voorbeeld 2: paleo atmosfeer
## De concentratie van CO₂ kan worden gemeten in luchtbellen in ijskernen, waarvan wordt aangenomen dat ze een steekproef vormen van de atmosfeer op een bepaald moment in het verleden.
## In dit geval zijn de concentratie en de leeftijd het resultaat van twee oorspronkelijke waarnemingen.
## Deze leveren de invoerwaarden voor de uiteindelijke waarneming.
## In dit alternatief voorbeeld worden de resultaten van de oorspronkelijke observaties gelinkt met de uiteindelijke observatie.
## Deze 2 resultaten komen overeen met de input variabelen gedefinieerd in de procedure.
## Opmerking:
## De 2 input variabelen zijn in dit voorbeeld apart gedefinieerd. Dit is niet noodzakelijk. We zouden als input variabelen de overeenkomende observedProperties kunnen specifieren.
## - ex:VariabeleCO2Observatie -> ex:CO2Concentratie
## - ex:VariabeleC14Observatie -> ex:C14Leeftijd

ex:AardAtmosfeer a sosa:FeatureOfInterest ;
   sosa:isFeatureOfInterestOf ex:PaleoCO2Observatie ;
.

.

ex:IjsKern a sosa:Sample, sosa:FeatureOfInterest ;
   sosa:isSampleOf ex:AardKorst ;
   sosa:isResultOf ex:BoringIjsKern ;
   sosa:isFeatureOfInterestOf ex:ExtractieIjsBel ;
.

ex:IjsBel a sosa:Sample, sosa:FeatureOfInterest ;

  sosa:hasFeatureOfInterest ex:AardAtmosfeer ;

      a qudt:QuantityValue ;
      qudt:hasUnit unit:PPM ; ## Parts per million (aantal deeltjes per miljoen deeltjes lucht
      qudt:numericValue 240.0 ;
  ] ;
  sosa:phenomenonTime [
    time:inTimePosition [
    time:hasTRS ex:BP ;
    time:numericPosition 7530 ;
    ] ;
  ] ;
  sosa:resultTime "2026-02-01T14:16:00+00:00"^^xsd:dateTime ;
  sosa:usedProcedure ex:ProcedurePaleoCO2Contentratie ;
  sosa:madeBySensor ex:PaleoReconstructie ;
  ## prov:used naar de resultaten volgt uit sosa:hasInputValue ⊂ prov:used (sosa-prov)
  sosa:hasInputValue ex:ResultaatC14Observatie, ex:ResultaatCO2Observatie ;
.

ex:ResultaatC14Observatie a qudt:QuantityValue ;
  sosa:isResultOf ex:C14Observatie ;
  a qudt:QuantityValue ;
  qudt:hasUnit unit:YR ;
  qudt:numericValue 7530.0 ;
  p-plan:correspondsToVariable ex:VariabeleC14Observatie ;
.

ex:ResultaatCO2Observatie a qudt:QuantityValue ;
  sosa:isResultOf ex:CO2Observatie ;
   a qudt:QuantityValue ;
   qudt:hasUnit unit:PPM ;
   qudt:numericValue 240.0 ;
   p-plan:correspondsToVariable ex:VariabeleCO2Observatie ;
.
