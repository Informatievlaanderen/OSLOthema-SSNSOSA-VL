# R5 — `sosa:hasInput` op de procedure, waarden op de uitvoering

!!! regel "In het kort"
    `sosa:hasInput` hoort **enkel** op een `sosa:Procedure`, om abstracte inputtypes te beschrijven.
    Op uitvoeringsniveau verwijzen `sosa:hasInputValue` (voor de waarde van een input van de
    procedure) of `prov:used` (voor wat anders gebruikt wordt) naar concrete entiteiten. Nooit
    `sosa:hasInput` met een concrete waarde op een waarneming.

## Waarom

SOSA beschrijft input en output op twee niveaus, als paar:

| | input | output |
|---|---|---|
| procedure (het type) | `sosa:hasInput` | `sosa:hasOutput` |
| uitvoering (de waarde) | `sosa:hasInputValue` (⊂ `prov:used`) | `sosa:hasResult` (⊂ `prov:generated`) |

`sosa:hasInput` zegt *welk soort* input de werkwijze vraagt ("een temperatuur"),
`sosa:hasInputValue` *welke waarde* een uitvoering gebruikte ("21,4 °C om 09:30"). Wie het type op
de uitvoering zet, haalt twee niveaus door elkaar ([SOSA en PROV-O](../samenhang/sosa-prov.md#5-inputwaarde-en-resultaat-een-spiegel)).

## Goed

```turtle
ex:afwijkingsprocedure a sosa:ObservingProcedure ;
    sosa:hasInput ex:gemeten-temperatuur ;           # het type
    sosa:hasOutput ex:afwijking .

ex:afwijking-0930 a sosa:Observation ;
    sosa:usedProcedure ex:afwijkingsprocedure ;
    sosa:hasInputValue ex:temperatuur-0930 ;          # de waarde
    sosa:hasResult ex:afwijking-resultaat-0930 .
```

## Fout

```turtle
ex:afwijking-0930 a sosa:Observation ;
    sosa:hasInput ex:temperatuur-0930 .   # een concrete waarde als type
```

## `sosa:hasInputValue` of `prov:used`?

- **`sosa:hasInputValue`** voor de waarde van een input die de procedure definieert.
- **`prov:used`** voor wat de uitvoering gebruikt zonder dat het een input van de procedure is: een
  machinaal-leermodel, een referentiebestand ([R6](r06.md)).

Beide zijn `prov:used` voor een PROV-toepassing; het verschil is de precisie.

## In de casussen

- [Energiemanagement](../casussen/ems.md): inputvariabelen in een drielaags model; de
  voorbeelden gebruikten tot 2026-10-01 `prov:used` voor inputwaarden en zijn toen naar
  `sosa:hasInputValue` omgezet.
- [Temperatuur en raam](../casussen/temperatuur-raam.md), [elektrisch raam](../casussen/elektrisch-raam.md):
  `sosa:hasInput` naar de variabele op de stap, `sosa:hasInputValue` naar het resultaat op de
  uitvoering.
