# R6 — Een ML-model is een artefact, geen sensor

!!! regel "In het kort"
    Een machinaal-leermodel is een `prov:Entity` (eventueel ook `it6:MachineLearningModel`),
    gegenereerd door een trainingsactiviteit. De software die het model gebruikt om voorspellingen
    te maken, is de `sosa:Sensor`. De uitvoering die het model toepast, gebruikt het met
    `prov:used`.

## Waarom

Een model wordt getraind (een activiteit), daarna is het een vast ding met een versie: een
entiteit. Het waarneemt niets; het wordt gebruikt door iets dat waarneemt of voorspelt. Wie het
model zelf als sensor modelleert, kan niet meer zeggen welke versie van het model welke
voorspelling maakte, en verliest de herkomst van het model (op welke data getraind).

## Goed

```turtle
ex:voorverwarmingsmodel a it6:MachineLearningModel , prov:Entity ;
    prov:wasGeneratedBy [ a prov:Activity ; prov:used ex:trainingsdata-2024 ] .

ex:temperatuurvoorspeller a sosa:Sensor ;
    sosa:implements ex:voorspellingsstap .

ex:voorspelling-0401 a sosa:Observation ;
    sosa:madeBySensor ex:temperatuurvoorspeller ;
    prov:used ex:voorverwarmingsmodel ;
    sosa:hasInputValue ex:historische-data ;
    sosa:hasResult ex:voorspeld-tijdstip .
```

## Fout

```turtle
ex:voorverwarmingsmodel a sosa:Sensor .
ex:voorspelling-0401 sosa:madeBySensor ex:voorverwarmingsmodel .
```

SSN/SOSA 2023 heeft geen eigenschap die een sensor met een gebruikt model verbindt: de band loopt
via de uitvoering.
