# R9 — Niet-kalendertijd via een benoemd tijdreferentiesysteem

!!! regel "In het kort"
    Gebruik `time:inTimePosition` met `time:hasTRS` naar een benoemde `time:TRS` (bv. `ex:BP` voor
    *Before Present*). Beschrijf het tijdreferentiesysteem met `skos:prefLabel` en
    `skos:definition`.

## Waarom

Niet elke tijd is een kalenderdatum. Radiokoolstofdatering geeft jaren vóór 1950; geologie werkt
met miljoenen jaren; een simulatie met modeltijd. Zo'n waarde als `xsd:gYear` schrijven, is
fout: het jaar 7530 is geen jaar in onze kalender. OWL-Time laat elke tijdschaal toe, op voorwaarde
dat je zegt welke. Een benoemd TRS met een definitie maakt de waarde interpreteerbaar en
vergelijkbaar.

## Goed

```turtle
ex:paleo-co2 sosa:phenomenonTime [
    a time:Instant ;
    time:inTimePosition [
        a time:TimePosition ;
        time:numericPosition 7530 ;
        time:hasTRS ex:BP
    ]
] .
ex:BP a time:TRS ;
    skos:prefLabel "Before Present"@en ;
    skos:definition "Aantal kalenderjaren vóór 1950."@nl .
```

## Fout

```turtle
ex:paleo-co2 sosa:phenomenonTime [ time:inXSDgYear "-5580"^^xsd:gYear ] .   # omgerekend, zonder te zeggen hoe
ex:paleo-co2 ex:leeftijdBP 7530 .                                          # eigen eigenschap, geen tijd
```
